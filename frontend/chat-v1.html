📌 GitHub Client ID 配置教程

1. 打开 GitHub 开发者平台：https://github.com/settings/developers

2. 登录你的 GitHub 账号，点击「New OAuth App」

3. 填写应用信息：

- Application name：自定义（如 AI助手）

- Homepage URL：http://127.0.0.1:5500/

- Authorization callback URL：http://127.0.0.1:5500/

4. 点击「Register application」

5. 创建完成后，复制「Client ID」填入本系统即可

📌 飞书 App ID 配置教程

1. 打开飞书开放平台：https://open.feishu.cn/

2. 登录企业管理员账号 → 进入开发者后台 → 创建「企业自建应用」

3. 创建完成后，复制「App ID（cli_开头）」

4. 进入：开发配置 → 安全设置 → 重定向 URL

5. 添加回调地址（必须完全一致）：http://127.0.0.1:5500/

6. 进入：权限管理 → 开通「contact:user.base:readonly」用户信息权限

7. 进入：应用发布 → 创建版本并发布应用

8. 把 App ID 填入本系统即可正常授权

📌 钉钉 Client ID 配置教程

1. 打开钉钉开发者后台：https://open-dev.dingtalk.com/

2. 登录 → 应用开发 → 企业内部应用 → 创建应用

3. 复制 **Client ID**（也叫 AppKey）

4. 左侧菜单：登录与授权 → 授权管理 → 网页授权

5. 添加 **回调域名/redirect_uri**：http://127.0.0.1:5500/

6. 权限管理 → 开通个人信息相关权限

7. 发布应用 → 完成配置

📌 GitHub Token 配置教程（代码上传专用）

✅ 生成地址：https://github.com/settings/tokens

1. Token name 随便填（如 ai-upload）

2. Expiration 选择 No expiration（永久有效）

3. Permissions 权限勾选 repo（必须全勾）

4. 点击 Generate token 生成

5. 生成后只显示一次，复制粘贴到输入框，丢失无法找回
